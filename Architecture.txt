# خريطة الموقع وقاعدة البيانات

هذا الملف يوضح صفحات العرض، صفحات التحكم، الـ API، والجداول المرتبطة بالمحتوى في قاعدة البيانات.

تمت المراجعة من:
- `apps/api/routes/api.php`
- `PublicApiController`
- `HomeCmsController`
- `AuthCmsController`
- `AdminCrudController`
- خدمات React داخل `apps/web/src/services`
- صفحات العرض داخل `apps/web/src/pages`
- صفحات لوحة التحكم داخل `apps/web/src/features/apanel/pages`

## APIs المهمة

| الوظيفة | API |
|---|---|
| محتوى صفحات login/forgot/reset | `GET /api/v1/auth-cms` |
| تسجيل الدخول | `POST /api/v1/auth/login` |
| طلب رابط reset password | `POST /api/v1/auth/forgot-password` |
| تنفيذ reset password | `POST /api/v1/auth/reset-password` |
| الاشتراك في النشرة | `POST /api/v1/newsletter-subscriptions` |
| إرسال حملة للمشتركين من اللوحة | `POST /api/v1/apanel/newsletter/subscriptions/send` |
| إدارة CMS Auth | `GET /api/v1/apanel/cms/cms-auth`<br>`PUT /api/v1/apanel/cms/cms-auth` |

## اللغات والترجمات

اللغات النشطة الحالية:

| اللغة | الحالة |
|---|---|
| `en` | نشطة |
| `uz` | نشطة |
| `ru` | نشطة |
| `ar` | نشطة |

جداول الترجمة المستخدمة في الصفحات المطلوبة تعتمد على عمود `locale`، ولذلك النظام جاهز لإضافة لغات جديدة بشرط:

1. إضافة اللغة في جدول `locales` وتفعيلها.
2. إدخال ترجمات اللغة الجديدة في جداول الترجمة المرتبطة بالمحتوى.
3. إدخال ترجمات قوالب البريد في `auth_email_template_translations`.
4. إدخال ترجمات صفحات auth في `auth_page_translations`.

## ملاحظات مهمة

- صفحات `/login` و `/forgot-password` و `/reset-password` أصبحت تدار من `/apanel/cms/cms-auth` وتقرأ المحتوى من `/api/v1/auth-cms`.
- قالب إيميل reset password يدار من `/apanel/cms/cms-auth`، ومدة صلاحية التوكن الفعلية تقرأ من `auth_email_templates.settings.expire_minutes`.
- فتح رابط `/reset-password` في المتصفح لا يعني أن التوكن صالح؛ الصلاحية يتم التحقق منها عند إرسال كلمة المرور الجديدة إلى `POST /api/v1/auth/reset-password`.
- Footer Newsletter يستخدم `web_footers` و `web_footer_translations` للنصوص الظاهرة، ويستخدم `newsletter_subscriptions` للتسجيل، ويستخدم `auth_email_templates` لقالب رسالة الشكر.
- إرسال حملة للمشتركين يتم من `/apanel/newsletter/subscriptions` ويسجل في `newsletter_campaigns`.
- لا يوجد اعتماد تشغيل على ملفات static data كمصدر محتوى لهذه الصفحات. ملفات React تحتوي بنية العرض و fallback labels فقط، بينما المحتوى التشغيلي يأتي من API والجداول.
