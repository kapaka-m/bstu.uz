# BSTU International Documentation Overview

This directory contains organized, non-redundant, and structured technical documentation for the BSTU International project.

## Directory Structure

- [01_project_milestones_and_architecture.md](01_project_milestones_and_architecture.md): Milestones, checklist, and system architecture.
- [02_academic_and_cms_migration_specifications.md](02_academic_and_cms_migration_specifications.md): CMS modules and page migration specs.
- [03_university_departments_and_centers.md](03_university_departments_and_centers.md): Official directory of centers and administrative departments.
- [04_faculty_migration_notes.md](04_faculty_migration_notes.md): Migration context for Faculty of Technology and Faculty of Engineering.
- [admin_panel_guide.md](admin_panel_guide.md): `/apanel/` routes, resources, permissions, and workflows.
- [api_endpoints_specification.md](api_endpoints_specification.md): Public, student, and `/apanel/` REST API endpoints.
- [student_system_guide.md](student_system_guide.md): `/student/` admissions, documents, contracts, payments, and support flows.
