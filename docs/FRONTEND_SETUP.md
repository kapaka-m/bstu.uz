# Frontend Setup

The React frontend lives in `apps/web`. It is a Vite + React 19 + Tailwind CSS app for the public website, student portal, and apanel frontend.

## Local Startup

```bash
cd apps/web
npm.cmd install
npm.cmd run dev
```

The local Laravel API should be available at:

```text
http://127.0.0.1:8000/api/v1
```

Configure it in `apps/web/.env`:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
VITE_DEFAULT_LOCALE=en
VITE_SUPPORTED_LOCALES=en,uz,ru,ar
```

Do not commit `.env`.

## Routing Boundaries

- Public routes use the normal public layout with `Header` and `Footer`.
- Student routes live under `/student/*` and are protected by `StudentRoute`.
- Apanel routes live under `/apanel/*` and are protected by `AdminRoute`.
- Backend authorization remains the source of truth; frontend guards are user experience protection only.

## Multilingual and RTL

- `LocaleProvider` manages locale, menus, settings, and translations.
- API requests include `locale` and `Accept-Language`.
- Arabic sets `dir="rtl"` on `html` and `body`.
- English, Uzbek, and Russian remain LTR.

## Content and Assets

- Academic public content is API-driven.
- Public CMS content is API-driven for news, blog, announcements, services, videos, green campus, center pages, and staff/profile pages.
- Do not add new production CMS content to `apps/web/src/data`.
- `apps/web/src/data` should only contain technical translation fallback files.
- Old static production data and archives were removed from the repository.
- `public/assets` contains shell assets only. Public content images and videos should come from API/media records.
- `dist` is generated by `npm.cmd run build`.
- Do not manually edit `package-lock.json` or `node_modules/.package-lock.json`.

## Troubleshooting

- Vite/Tailwind `spawn EPERM`: run the command from a normal Windows terminal with access to Node native binaries.
- Backend unavailable: start Laravel API and verify `VITE_API_BASE_URL`.
- CORS/API URL problems: check Laravel CORS settings and restart Vite after `.env` changes.
- Raw translation keys: verify `/api/v1/translations?locale=en` or the selected locale.
- Broken image URLs: verify public asset paths, `/storage/...` links, or API media URL generation.
